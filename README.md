FishHub is a modern frontend landing page design for a fish shop / aquarium business.  
The website is designed with a clean, fullscreen hero style, attractive UI, and responsive layout.

## 🌊 Frontend Design

- Modern fish shop landing page
- Fullscreen hero section
- Clean and professional UI
- Responsive layout for desktop, tablet, and mobile
- Smooth visual design
- Aquarium / fish shop themed interface
- Frontend only project

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- CSS
- HTML

## 📁 Project Structure

```bash
FishHub/
├── public/
├── src/
├── index.html
├── package.json
├── vite.config.ts
└── README.md
````

## 🚀 How to Run

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

## 📌 Project Purpose

This project was created to showcase a modern frontend design for a fish shop website.
It can be used as a landing page for aquarium shops, fish stores, aquatic product sellers, or pet fish businesses.
